## What technology does Meta push, and what is the strategic agenda?

### Takeaway
Meta's 2026 push is its own hosted model family (Muse Spark, Muse Image, SAM 3.1, Muse Code) through a paid Meta Model API, alongside its open-weights models. Past hackathons pushed Llama models (3.1, 3.2, 4 Scout, 4 Maverick) and the Llama API. The strategic signal is a shift from pure open-weights distribution to a hosted API, with developers asked to build vertical and real-world applications.

### Cited Findings
- Muse Spark 1.1 and Meta Model API: Meta's first paid AI model API, hosted and pay-per-token; launched July 2026 as a public preview. Sources: [propakistani.pk](https://propakistani.pk/2026/07/11/meta-launches-muse-spark-1-1-with-its-first-paid-ai-model-api/); [letsdatascience.com](https://letsdatascience.com/news/meta-unveils-muse-spark-11-opens-developer-preview-4e60d164) (search snippets). Earlier: private-preview API for selected partners in April; Meta repeatedly delayed the broader release (single source: [news.latent.space](https://news.latent.space/story/clu_ext31w), search snippet).
- Global hackathon themes push Meta's models into "your world" and into hard domains (robotics, manufacturing, energy, materials), per the [official page](https://dev.meta.ai/events/global-hackathon) (fetched).
- Past Llama events used Llama 3.1 and 3.2 (Pan-LATAM, on-device track requires Llama 3.2 1B/3B) and Llama 4 Scout/Maverick with the Llama API (LlamaCon, 2025). Sources: [lablab Pan-LATAM](https://lablab.ai/event/llama-impact-hackathon-pan-latam) (fetched); [ai.meta.com LlamaCon hackathon](https://ai.meta.com/blog/llamacon-hackathon/) (fetched).
- Meta's wearables push: Device Access Toolkit (phone-side SDK, camera, 5-mic array, speakers on Meta glasses), developer preview Dec 2025 ([developers.meta.com](https://developers.meta.com/blog/introducing-meta-wearables-device-access-toolkit/), search snippet).

### Inferences
- Meta has shifted from open weights only to a hosted API with paid tiers. A hackathon that requires the Meta Model API makes Meta's revenue the goal, not only developer goodwill.
- Judges of the Startup track will look for projects that could realistically run on the Meta Model API, so pricing and latency matter for the pitch.

### Gaps
- No official Meta statement on what it wants to showcase beyond the event page text. No Meta DevRel post explaining the 2026 agenda found.
- Whether Muse models are mandatory: not stated.

## Past winners of Meta hackathons (2024-2026)

### Takeaway
Past Meta-branded winners were mostly tools that solved a clear user problem with a Llama model (government benefits, compliance, accessibility, education). The LlamaCon 2025 SF winners were enterprise tools (expert search, fraud/compliance, CCTV analytics, geology). Only the LlamaCon 2025 and SF 2024 winners have a confirmed official source. The LATAM winners are the most relevant to Chile and are sourced from lablab.ai summaries.

### Cited Findings

**LlamaCon Hackathon, San Francisco, 2025** (source: [ai.meta.com/blog/llamacon-hackathon](https://ai.meta.com/blog/llamacon-hackathon/), fetched; date not stated, article dated May 13, 2025)
- 238 participants from 600+ registrants; 44 submitted projects; 24 hours to build; required Llama API, Llama 4 Scout, Llama 4 Maverick (or combination); $35K cash prizes total; two judging rounds narrowed to six finalists. Judging weights not stated; judge names not provided.
- 1st, OrgLens: expert-matching system building knowledge graphs and profiles from Jira, GitHub, internal docs, and resumes; users query a person's "digital twin". Built with React, Tailwind, Django, GitHub API, Llama API. Team size not stated.
- 2nd, Compliance Wizards: transaction analyzer flagging fraud with a custom risk algorithm; email acknowledgements; voice assistant reporting; uses Llama API multimodality to search client news.
- 3rd, Llama CCTV Operator: detects custom surveillance events defined in plain language, no fine-tuning, using Llama 4 image understanding on footage sampled every five frames. Led by Agajan Torayev.
- Best Llama API usage, Geo-ML: Llama 4 Maverick and GemPy turn 400-page geology reports into a domain-specific language, then generate 3D subsurface models. Created by geologist William Davis.
- Finalist Team Concierge (not a winner): brought own GPUs; fine-tuned Llama 4 Maverick with Meta's Synthetic Data Generation tool.
- Dollar amounts for 1st, 2nd, 3rd not stated in the article.

**Llama Impact Hackathon, San Francisco, 2024** (source: [lablab.ai summary](https://lablab.ai/blog/llama-impact-hackathon-sf-summary), fetched; article dated Nov 20, 2024)
- Hybrid (online and on-site at the MindsDB venue in SF). 1,375 participants, 228 teams, 83 AI applications. Prize pool "over $20,000". Team sizes not stated. Judging criteria not stated. Judge names not stated.
- On-site: 1st ($5,000) Llama Navigator AI, a Chrome extension for finding information on any website; 2nd ($3,000) Compllama, construction compliance with location-specific building codes; 3rd ($2,000) Farmipole, AI agricultural welfare platform for Indian farmers with multilingual support.
- Online: 1st ($3,000) Bridging Underprivileged to Government Support, personalized notifications about eligible public benefits; 2nd ($1,500) Clear Bureau, Chrome extension simplifying government websites; 3rd ($500) Port State Control PSC Report Parser.
- Best Use awards: Restack ($1,000) to Compllama; LlamaIndex ($1,000) to BrightStart (child-health resources, Sub-Saharan Africa); Solo Tech ($500) to Llama Navigator AI; MindsDB Knowledge Base 1st ($1,000) Farmipole, 2nd ($750) LinguaLink (real-time medical translation for low-resource languages), 3rd ($500) Llama Navigator AI; Together AI ($2,500 credits) Clara (social service action plans into tasks via AI voice agent).

**Llama Impact Pan-LATAM Hackathon, online, Latin America (year inferred 2024)** (source: [lablab.ai event page](https://lablab.ai/event/llama-impact-hackathon-pan-latam), fetched; winners from [lablab.ai Pan-LATAM summary](https://lablab.ai/blog/llama-impact-pan-latam-hack-summary), search snippet)

### Takeaway
